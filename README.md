# AErender-Launcher
An attempt to rewrite AErender Launcher from scratch using C#.

Currently, the project is in the deep Alpha state, as I am still in 
the process of migrating all the features from legacy Launcher. 
The rendering part is already done and ready to use.

You can find the latest alpha release in the [Releases](https://github.com/Night-Sky-Studio/AErender-Launcher/releases) section.

Any encountered bugs/crashes should be reported in the [Issues](https://github.com/Night-Sky-Studio/AErender-Launcher/issues) section.
